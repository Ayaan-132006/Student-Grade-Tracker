# Student-Grade-Tracker
A desktop-based Student Grade Tracker developed using Java Swing. This application allows users to manage student records, calculate performance statistics, and store data permanently using file handling.

📌 Project Overview

The Student Grade Tracker is a simple academic management system designed to help users record and analyze student grades. The application provides a graphical user interface (GUI) built with Java Swing, making it easy to add student information, view records, and generate basic performance statistics.

All student records can be saved to a text file, ensuring that data is stored outside the program for future reference.

✨ Features


Add student names and grades through a user-friendly GUI
Display student records in a table
Calculate:
Average score
Highest score
Lowest score
Store student data using file handling
Save records to a text file (students.txt)
Object-Oriented Programming (OOP) implementation
Clean and responsive Java Swing interface
